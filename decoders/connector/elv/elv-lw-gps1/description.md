The ELV LoRaWAN® GPS Tracker 1 uses a GNSS module for position determination, the corresponding data is sent via the LoRaWAN® network. The positioning can be started via the integrated accelerometer or contact interface. The device can be supplied in a wide voltage range of 5 to 40 V. Thanks to its compactness, the wide input voltage range and the various modes for position determination, the tracker can be used in many applications.
